# Agente Analítico de Control de Riesgo

Presentación técnica-ejecutiva para validar enfoque, herramientas y recursos necesarios para desarrollar un backend agéntico de consulta analítica sobre modelos semánticos existentes en Microsoft Fabric / Power BI.

## Archivo principal

- `index.html`: presentación autocontenida con HTML, CSS, JavaScript y SVG inline.

## Audiencia

Equipo funcional-técnico de IA en contexto bancario.

## Objetivo

Validar si el enfoque propuesto —catálogos como fuente de verdad, orquestación con Microsoft Agent Framework 1.0, ejecución controlada contra Fabric/Power BI y exposición futura vía MCP— es viable dentro de los estándares corporativos.
