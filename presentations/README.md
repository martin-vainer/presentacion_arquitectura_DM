# Presentaciones

Cada carpeta dentro de este directorio representa una presentación independiente.

## Convención de estructura

```text
presentations/<slug>/
  index.html
  README.md
  docs/
    BRIEF.md o CONTEXTO_CODEX.md
    DECISIONES.md
```

## Convención de nombres

Usar slugs cortos, descriptivos y en minúscula:

- `datamart-riesgos`
- `estrategia-ia`
- `modernizacion-frontend`
- `gobierno-datos`

## Regla principal

Una presentación no debe depender de otra para funcionar. Si se abre su `index.html` localmente, debe estar lista para exponerse.
