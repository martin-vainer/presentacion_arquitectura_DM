# DATAMART de Riesgos

Presentación ejecutiva web sobre arquitectura y gobierno de datos para Control de Riesgos.

## Archivo principal

- `index.html`: deck autocontenido con HTML, CSS y JavaScript inline.

## Documentación

- `docs/CONTEXTO_CODEX.md`: brief original de trabajo, restricciones, audiencia, narrativa y criterios de calidad.
- `docs/DECISIONES.md`: bitácora de decisiones narrativas, visuales y de interacción.

## Rol dentro del repositorio

Esta presentación funciona como primera implementación y referencia de calidad para futuras presentaciones generadas por IA.

No debe tratarse como una plantilla literal para copiar y pegar sin criterio. Es una referencia de:

- narrativa ejecutiva;
- sobriedad visual;
- uso de una paleta consistente;
- estructura problema → propuesta → valor → implementación → cierre;
- documentación de decisiones.
